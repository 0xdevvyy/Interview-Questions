# Interview Questions

A collection of coding challenges, interview questions, and solutions completed as part of my software developer interview preparation.

## About

This repository contains my solutions to technical interview questions and coding challenges from various platforms, including:

* HackerRank
* TestDome
* SQL Challenges
* Software Development Exercises
* Technical Interview Practice

I graduated in 2025 and have been pursuing Software development opportunities since then. Over the past year, I have participated in multiple technical interviews and coding assessments while continuing to improve my skills through consistent practice and project development.

My job search has been challenging. After more than a year of unemployment and eight interview, I have received only two job offers, both with compensation that did not align with my long term career goals. There have been periods where progress felt slow and difficult to measure, like standing still while waiting for the right opportunity.

Rather than allowing that frustration to stop me, I chose to keep learning, building, and improving every day. This repository serves as a record of that journey documenting my problem solving practice, interview preparation, and commitment to becoming a better Software developer.

## Why This Repository Exists

As an aspiring Software developer navigating a challenging job market, I use this repository to:

* Build consistency through daily practice
* Improve problem-solving skills
* Strengthen SQL and database knowledge
* Prepare for technical interviews
* Prepare for coding assessments
* Document my learning journey
* Showcase technical growth
* Demonstrate resilience and continuous learning

This repository represents more than completed coding challenges. It reflects the effort to keep moving forward during a difficult period, maintain discipline despite setbacks, and continue developing the skills needed to succeed in software developer.
